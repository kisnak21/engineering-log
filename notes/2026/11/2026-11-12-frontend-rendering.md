## Fokus

Rendering frontend dan hydration

## Konsep inti

### Server dan client rendering

HTML dapat disiapkan di server atau dibentuk di browser, dengan tradeoff berbeda untuk loading dan interaktivitas.

### Hydration

Hydration menghubungkan JavaScript aplikasi ke HTML yang sebelumnya sudah dirender.

## Latihan

1. Nonaktifkan JavaScript sementara dan periksa bagian halaman yang tetap tersedia.

2. Bandingkan HTML awal dengan DOM setelah aplikasi interaktif.

3. Identifikasi komponen yang benar-benar memerlukan JavaScript klien.
