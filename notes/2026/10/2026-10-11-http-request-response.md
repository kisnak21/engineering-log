## Konsep inti

### HTTP semantics

Method dan status code menyampaikan maksud operasi serta hasilnya tanpa bergantung pada tampilan aplikasi.

### Headers

Header membawa metadata seperti tipe konten, aturan cache, autentikasi, dan kemampuan klien.
